# Jiku Solutions — Kit de marca

Rediseño vectorial del logo de Jiku Solutions. A diferencia del render original
(imagen de mapa de bits), estos archivos son **vectoriales**: nítidos a cualquier
tamaño, editables y con archivos limpios para cada uso.

## Archivos

| Archivo | Uso |
|---|---|
| `jiku-logo.svg` | Logo principal (símbolo + wordmark) para fondos claros |
| `jiku-logo-dark.svg` | Logo para fondos oscuros |
| `jiku-icon.svg` | Solo símbolo, en contenedor navy — favicon, app icon, avatar |
| `png/` | Versiones PNG con fondo transparente, listas para redes/presentaciones |
| `index.html` | Vista del kit completo (ábrelo en el navegador) |

## Paleta

| Color | Hex | Uso |
|---|---|---|
| Azul base | `#2547FF` | Extremo inferior del gradiente |
| Azul medio | `#2F7BFF` | Centro del gradiente |
| Cian | `#28D7EF` | Extremo superior del gradiente |
| Navy | `#0D1B2A` | Texto del wordmark y fondo del icono |

## Tipografía

**Poppins** — Extra Bold (800) para "Jiku", Medium (500) con letter-spacing
amplio para "solutions".

## Qué cambió respecto al original

- Símbolo "J" reconstruido como trazo vectorial limpio (antes: bisel 3D ruidoso).
- Eliminada la sombra difusa que le daba aspecto de imagen generada por IA.
- Bordes vectoriales: se mantiene nítido incluso a 16px (favicon).
- Gradiente consistente y wordmark alineado ópticamente con el símbolo.
- Variantes para fondo claro, oscuro y como icono de app.
